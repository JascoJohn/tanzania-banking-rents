## BoT and financial-inclusion intake template

Save each series as a CSV in `data/raw/bot/` with exactly these columns (template: `data/raw/bot/TEMPLATE_bot_series.csv`), register it with `python -m tzbank manifest`, then `run all`. `tzbank.ingest.bot` validates every file and stacks them into `data/interim/bot_long.csv`; problems are listed in `reports/validation/bot_intake_issues.csv` (a wrong header, a missing source, a non-date period or a duplicate series_id + period_end are critical).

| Column | Content |
| --- | --- |
| series_id | Stable identifier, e.g. BOT_TBILL_364D |
| series_name | Plain description |
| category | sector_totals, rates, reserve_requirements, credit_by_activity, interest_rates_spreads, regulation, payments, inclusion, other |
| scope | sector or bank |
| bank_name | Required when scope = bank |
| frequency | daily, weekly, monthly, quarterly, annual, event |
| period_end | yyyy-mm-dd |
| value | Number (text only when unit = text) |
| unit | TZS (full shillings), TZS million, TZS billion, USD, ratio (decimal), count, index, number, text |
| source_document | Document title or Doc ID (required) |
| page_table | Page or table |
| publication_date | yyyy-mm-dd, when the figure became public |
| confidence | HIGH, MEDIUM, LOW |
| notes | Free text |

Worked example: `data/raw/bot/bot_tbond_auction_yields.csv` (category rates, 371 auction yields).

## Raw files to fetch (public repository)

The public repository holds the owner-compiled inputs. These raw files are third-party material and are not redistributed. Fetch each one, save it under `data/raw/` at the path shown, and check it with `python -m tzbank info` (the sha256 must match `data/raw/MANIFEST.csv`; a different copy of a document can change the results).

| Folder under `data/raw/` | Files | What they are | Where to get them |
| --- | --- | --- | --- |
| `Treasury_` | 1 | BoT Treasury bond auction calendar Sep 2012 - Nov 2026 (number, title, date; no yields). R | BoT Treasury bond auction calendar: https://www.bot.go.tz/TBonds (auction results list, saved as Excel under the MANIFEST file name). |
| `analyst_reports/` | 17 | Raw input | Local broker notes: the brokers (iTrust, Solomon, Kadoo, TSL, Vertex); the register `analyst_reports/register.csv` is in the repository. |
| `bot/` | 379 | Further BoT data file | Bank of Tanzania Treasury bond auction pages: `python -m tzbank.ingest.auction_results` (network; saves `bot/auctions/<auction>_<days>.json` and the list page from https://www.bot.go.tz/TBonds). |
| `documents/` | 289 | Bank annual report, interim statement or Phase 1 extraction-kit file | Bank annual reports, BoT, IMF, World Bank and other reports: the URL of each document is in `docs/SOURCE_REGISTER.md` (Doc ID, URL); the file name to use is in MANIFEST. |
| `dse/` | 2952 | DSE-hosted company document (PDF) listed on the company's financial-reports or disclosures | Dar es Salaam Stock Exchange site snapshots: `python -m tzbank.ingest.dse_library fetch` (network; DSE terms of use apply). A fresh fetch can differ from the snapshots used here. |
